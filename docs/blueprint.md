# **App Name**: AyudaYa

## Core Features:

- Management Portal Simulation: Simulate a management portal interface as the starting point.
- Help Button Navigation: Implement a help button on the management portal that navigates to a dedicated help page.
- Help Article Display: Display a collection of help articles on the help page, categorized by topic. Replicates the 'Artículos populares' and 'Aprovecha el Portal al máximo' sections as shown in the provided image.
- Contextual Search: Allow users to search for help articles using a search bar on the help page. Recommend related articles based on the search term.
- Topic Navigation: Provide quick access to common help topics such as 'Potenciar tu negocio', 'Autogestión total', etc., using buttons or a similar UI element on the help page.
- Online Help Menu: Display a help button at the top of the help page that unfolds to expose a menu of help options ('Ayuda en linea').

## Style Guidelines:

- Primary color: Soft pink (#F4DCD6) to match the brand's gentle and supportive tone.
- Background color: Light gray (#F5F5F5) for a clean, neutral base that emphasizes content.
- Accent color: Burgundy (#9F2B68), a slightly darker analogous color with higher saturation, for highlighting key interactive elements.
- Headline font: 'Belleza', a humanist sans-serif for headings and titles.
- Body font: 'Alegreya', a humanist serif font used for article bodies, for a comfortable reading experience.
- Use minimalist line icons to represent different help categories and actions. Ensure the style matches the overall clean aesthetic.
- Implement a responsive layout that adapts to different screen sizes, maintaining a consistent look and feel across devices.
